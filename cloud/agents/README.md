# Cognira BTI Agent Development Tools

This folder contains agent development support for the Cognira BTI hackathon deployment:

```text
cloud/agents/
├── cognira_bti_agent/
├── evals/
├── agent_manifest.yaml
├── agents_cli_setup.sh
├── deploy_agent_runtime.sh
└── run_agent_local.sh
```

It is designed to align with Google Agent Development Kit and Agents CLI style workflows while keeping the GKE deployment as the primary hackathon runtime.
